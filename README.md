# Teoria dos Grafos — Implementações em Python 🌐

Este repositório contém implementações de estruturas de dados para **Grafos** em Python, cobrindo representações por **Lista de Adjacência** e **Matriz de Adjacência**, tanto para grafos **direcionados (digrafos)** quanto **não direcionados**.

---

## 📌 Conteúdo do Repositório

O repositório está organizado em módulos principais de implementação, scripts de geração de dados e suítes de teste:

### 🛠️ Implementações Principais
* **`meu_grafo_lista_adj_dir.py`**: Grafo direcionado representado por **Lista de Adjacência**.
* **`meu_grafo_lista_adj_nao_dir.py`**: Grafo não direcionado representado por **Lista de Adjacência**.
* **`meu_grafo_matriz_adj_dir.py`**: Grafo direcionado (digrafo) representado por **Matriz de Adjacência**.
* **`meu_grafo_matriz_adj_nao_dir.py`**: Grafo não direcionado representado por **Matriz de Adjacência**.

### 🧪 Scripts de Teste e Validação
* **`grafo_lista_adj_dir_test.py`**: Testes unitários / de validação para a lista de adjacência direcionada.
* **`grafo_lista_adj_test_nao_dir.py`**: Testes para a lista de adjacência não direcionada.
* **`grafo_matriz_adj_dir_test.py`**: Testes para a matriz de adjacência direcionada.
* **`grafo_matriz_adj_nao_dir_test.py`**: Testes para a matriz de adjacência não direcionada.
* **`teste.py` / `teste_Matriz_adj_dir.py` / `teste_lista_adj_nao_dir.py`**: Scripts de execução de testes rápidos de bancada.

### 🎲 Utilitários
* **`gerar_grafos_teste.py`**: Script para geração automática de grafos para testes e benchmarking.
